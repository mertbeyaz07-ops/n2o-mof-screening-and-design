# PMTransformer Models

This directory contains the scripts, configuration files, and NPZ datasets used for the four PMTransformer models (TF-1–TF-4).

The trained best-checkpoint files are not included in this GitHub repository because of GitHub's file-size limitations. They are archived on Zenodo and can be accessed using the persistent link below.

**Zenodo DOI:** [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22119688.svg)](https://doi.org/10.5281/zenodo.22119688)

## Checkpoint–Model Mapping

| Model | Checkpoint file  |
| ----- | ---------------- |
| TF-1  | `TF-1_best.ckpt` |
| TF-2  | `TF-2_best.ckpt` |
| TF-3  | `TF-3_best.ckpt` |
| TF-4  | `TF-4_best.ckpt` |

The corresponding model configurations and NPZ files are provided in the `configs/` and `npz/` directories, respectively.
